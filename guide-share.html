처음 한 번만: 세일즈원에 코드 붙여넣는 법

이 도구는 세일즈원 화면에 코드를 붙여넣어 실행해요. 따로 설치할 것은 없어요.

  1. 크롬에서 세일즈원(nsalesone.gshs.co.kr)에 로그인하고, 도구를 쓸 화면을 엽니다.
  2. 키보드 F12를 누르면 오른쪽(또는 아래)에 창이 열려요. 위쪽 탭 중 Console(콘솔)을 누릅니다.
  3. 맨 아래 > 표시가 있는 줄을 클릭하고 Ctrl+V로 붙여넣은 뒤 Enter.
  4. 처음 한 번은 크롬이 붙여넣기를 막고 allow pasting을 입력하라고 해요. 그 줄에 allow pasting을 그대로 치고 Enter, 다시 붙여넣으면 됩니다.
  5. 세일즈원 화면 오른쪽에 도구 창이 뜨면 성공이에요. 쿠폰 에이전트 창은 오른쪽 위쪽까지 길게 떠요. F12 창은 다시 F12를 눌러 닫아도 돼요.
세일즈원 화면을 새로고침하면 도구 창이 사라져요. 다시 쓰려면 같은 방법으로 다시 붙여넣으면 됩니다. (쿠폰 에이전트는 등록한 쿠폰 내역을 기억하고 있어서 다시 붙여넣어도 이어서 할 수 있어요.)
등록하는 사람

쿠폰 에이전트

언제 쓰나

상품 가격을 쿠폰으로 맞춰야 할 때. 예) 모바일라이브 방송 쿠폰, 기간 행사 쿠폰. 상품코드와 원하는 고객 가격(또는 할인율·할인액)만 알면 돼요.

준비물

  • 파일 1_쿠폰에이전트.html (공유받은 폴더에 있어요. 더블클릭하면 크롬에서 열려요. 인터넷에 아무것도 보내지 않아요.)
  • 엑셀에 정리한 상품코드 | 가격 또는 할인 두 열 (최종가 89000, 할인율 15%, 할인액 -9000)
  • 쿠폰 기간 (모바일라이브면 방송 시작 시각만)

순서

  1. 1_쿠폰에이전트.html을 열고 1번 칸에 엑셀의 상품코드·가격 또는 할인 두 열을 복사해 붙여넣습니다. 2열은 적는 모양으로 구분해요. 숫자만 쓰면 고객 최종가(89000), %를 붙이면 할인율(15%), 앞에 -를 붙이면 할인액(-9000)이고, 할인율·할인액은 판매가 기준이에요. 상품마다 섞어 써도 돼요.
  2. 쿠폰 기간과 브랜드를 적습니다. 일반 행사는 시작·종료 날짜와 시간을 고르세요. 종료는 기본이 시작과 같은 날 23:59이고, 그 분의 끝(23:59:59)까지 적용돼요. 모바일라이브는 방송일시와 방송 시간(분)만 넣으면 쿠폰 기간이 방송 30분 전부터 방송 종료까지로 자동으로 잡혀요.
  3. 세일즈원 쿠폰관리 > 상품코드 쿠폰조회에서 같은 상품코드를 조회(진행상태: 전체)하고, 표의 줄을 전부 복사해 2번 칸에 붙여넣습니다(머리글은 없어도 돼요). 지금 판매가와 이미 걸린 쿠폰을 보고 필요한 할인을 계산해요. 할인율(15%)이나 할인액(-9000)으로만 적었다면 이 칸은 비워도 돼요(최종가·마진 점검은 생략).
  4. 세일즈원 상품관리 > 상품 조회/수정에서 같은 상품코드를 조회하고, 표의 줄을 복사해 3번 칸에 붙여넣습니다. 직매입은 당사 100%, 위수탁은 당사·협력사 반반으로 부담이 자동으로 정해져요. 이 칸은 선택이에요. 비워 두면 모두 당사 부담으로 계산해요.
  5. 쿠폰 만들기를 누릅니다. 아래에 만들 쿠폰, 상품별 계산, 고객 최종가 미리보기가 나와요. 차단이 있으면 내용을 읽고 고친 뒤 다시 누르세요. 가격이 원하는 대로인지 꼭 한 번 보세요.
  6. 맨 아래 ④ 다음 단계 카드의 세일즈원 입력 코드 복사를 누릅니다. 화면 위 ①~④ 단계 표시줄을 누르면 그 단계로 바로 이동해요.
  7. 세일즈원 쿠폰관리 > 쿠폰등록 화면에서 F12 → Console에 붙여넣고 Enter. 화면 오른쪽 위에 🤖 쿠폰 에이전트 창이 열려요. 창이 세일즈원 버튼을 가리면 창의 옮기기로 왼쪽으로 옮길 수 있어요(고른 쪽을 기억해요).
  8. 남은 쿠폰 전부 등록을 누르면 [추가] → 칸 채우기 → 저장 → 채널(인터넷·M커머스 + VOD 매장 일괄 추가, 1번에서 VOD 전용 쿠폰을 켰으면 VOD 매장만, VOD 매장 제외를 켰으면 인터넷·M커머스만) 넣기까지 쿠폰마다 차례로 하고, 새 쿠폰코드를 기록해요. 한 장씩 하려면 쿠폰별 이 쿠폰만 등록을 누르세요. 저장만 실패했을 때는 넣은 값 아래 저장 다시 시도로 이어서 할 수 있어요.
  9. 모든 쿠폰에 쿠폰코드가 기록되면 상품-쿠폰 일괄 등록을 누릅니다. 상품 일괄등록 탭에서 양식 엑셀을 올리고 [쿠폰 상품 일괄등록]까지 눌러 줘요. 중간에 공헌이익 승인요청 창이 뜨면 요청사유 '당사직매입 상품'을 골라 [요청]까지 알아서 눌러요. 직접 올리고 싶으면 엑셀 받기로 양식 파일만 받을 수도 있어요.
  10. 승인권자에게 승인 요청을 알립니다. (승인 전에는 쿠폰이 적용되지 않아요.)
  11. 다음 작업을 시작하기 전에 쿠폰 내역 초기화를 눌러 지난 내역을 지웁니다.

주의할 점

  • 쿠폰이 도는 동안에는 세일즈원 화면을 클릭하거나 다른 탭으로 옮기지 마세요. 멈춰야 하면 창의 닫기를 누르세요.
  • 칸 값이 계획과 다르면 저장하지 않고 멈춰요. 이유가 창에 적혀 있으니 읽어 보고, 필요하면 직접 고쳐 저장한 뒤 직접 저장했어요 → 쿠폰코드 기록으로 코드를 넣어 주세요. 잘못 기록된 코드는 코드 고치기로 바로잡을 수 있어요.
  • 쿠폰 이름은 정해진 양식으로 자동으로 들어가요. 쿠폰설명 = 브랜드_날짜_쿠폰율/액_당사·반반, 노출쿠폰명 = 브랜드 앱할인 쿠폰율/액.
  • 고객쿠폰(등록자 신지원·이진선·나희석, 쿠폰설명에 마이샵·매장 전용·리모콘·VIP가 들어간 쿠폰)은 계산에서 빼요. 더블쿠폰은 표에 표시가 없어서 2번 칸 아래 고급 설정의 더블쿠폰 코드에 직접 적어 주세요.
  • 엔니튜드 15% 쿠폰은 당사 10% / 협력사 5% 부담으로 만들어요. 1번 칸 아래 고급 설정의 엔니튜드 체크(기본 켜짐)를 끄면 다른 위수탁 상품처럼 반반(7.5% / 7.5%)이에요.
  • 공헌이익이 마이너스가 되는 상품은 승인권자가 따로 승인해야 해요.
  • 기간과 고급 설정은 이 PC에 자동으로 기억돼요. 상품코드·조회 결과·매입형태·브랜드 칸은 열 때마다 비어 있고, 회색 글씨는 예시일 뿐이니 칸을 눌러 새로 넣어 주세요.

막히면

  • 붙여넣기가 안 돼요 → 콘솔에 allow pasting을 먼저 입력하고 Enter, 다시 붙여넣기.
  • 도구 창이 안 보여요 → 세일즈원 화면 오른쪽([옮기기]를 눌렀다면 왼쪽)을 확인해 주세요. 새로고침했다면 다시 붙여넣기.
  • F12가 안 열려요 → 회사 PC 설정으로 막혀 있을 수 있어요. 김지영님께 알려 주세요.
  • 등록 중 멈췄어요 → 창에 적힌 이유를 읽고, 세일즈원에서 해당 쿠폰이 저장됐는지 확인한 뒤 이어서 진행.
  • 그 밖의 문제는 창의 내용을 캡처해서 김지영님께 보내 주세요.
