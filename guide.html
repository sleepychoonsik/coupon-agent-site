② 승인권자쿠폰 승인 에이전트화면 쿠폰관리 › 쿠폰등록 (쿠폰목록)쿠폰목록의 쿠폰을 위에서부터 차례로 모두 승인해요.
③ 승인권자공헌이익 승인 에이전트화면 상품 › 승인/제한관리 › 판매 승인/제한 › 공헌이익 마이너스 승인 › [승인처리] 탭목록의 승인요청 건을 한 건씩 차례로 승인해요. 패션2팀 건은 자동으로 빼요.
① 등록자: 쿠폰 등록 + 상품 연결→② 승인권자: 쿠폰 승인→③ 승인권자: 공헌이익 마이너스 상품 승인
등록한 사람과 승인하는 사람은 달라야 해요. ②, ③은 반드시 승인권자 PC에서 승인권자 아이디로 로그인해서 실행해 주세요.

처음 한 번만: 세일즈원에 코드 붙여넣는 법

세 도구 모두 세일즈원 화면에 코드를 붙여넣어 실행해요. 따로 설치할 것은 없어요.

  1. 크롬에서 세일즈원(nsalesone.gshs.co.kr)에 로그인하고, 도구를 쓸 화면을 엽니다.
  2. 키보드 F12를 누르면 오른쪽(또는 아래)에 창이 열려요. 위쪽 탭 중 Console(콘솔)을 누릅니다.
  3. 맨 아래 > 표시가 있는 줄을 클릭하고 Ctrl+V로 붙여넣은 뒤 Enter.
  4. 처음 한 번은 크롬이 붙여넣기를 막고 allow pasting을 입력하라고 해요. 그 줄에 allow pasting을 그대로 치고 Enter, 다시 붙여넣으면 됩니다.
  5. 세일즈원 화면 오른쪽에 도구 창이 뜨면 성공이에요. 쿠폰 에이전트는 오른쪽 위쪽까지 길게, 두 승인 에이전트는 오른쪽 아래에 작게 떠요. F12 창은 다시 F12를 눌러 닫아도 돼요.
세일즈원 화면을 새로고침하면 도구 창이 사라져요. 다시 쓰려면 같은 방법으로 다시 붙여넣으면 됩니다. (등록 에이전트는 등록한 쿠폰 내역을 기억하고 있어서 다시 붙여넣어도 이어서 할 수 있어요.)
등록하는 사람

① 쿠폰 에이전트 (등록)

언제 쓰나

상품 가격을 쿠폰으로 맞춰야 할 때. 예) 모바일라이브 방송 쿠폰, 기간 행사 쿠폰. 상품코드와 원하는 고객 가격(또는 할인율·할인액)만 알면 돼요.

준비물

  • 크롬에서 연 세일즈원 쿠폰관리 > 쿠폰등록 화면
  • 아래 버튼으로 복사하는 쿠폰 에이전트 코드 (또는 agent.txt를 열어 전체 복사)
  • 엑셀에 정리한 상품코드 | 가격 또는 할인 두 열 (최종가 89000, 할인율 15%, 할인액 -9000)
  • 쿠폰 기간 (모바일라이브면 방송 시작 시각만)

순서

  1. 세일즈원 쿠폰관리 > 쿠폰등록 화면에서 F12 → Console에 쿠폰 에이전트 코드를 붙여넣고 Enter. 화면 오른쪽 위에 🤖 쿠폰 에이전트 창이 열려요. 창이 세일즈원 버튼을 가리면 창의 옮기기로 왼쪽으로 옮길 수 있어요(고른 쪽을 기억해요).
  2. 창의 🔎 사전검증 열기를 누르면 새 창에 쿠폰 사전검증 화면이 열려요. (팝업이 막히면 주소창 오른쪽의 팝업 차단 표시를 눌러 허용하세요.) 이렇게 열어야 두 창이 서로 통해요.
  3. 사전검증 화면 1번 칸에 엑셀의 상품코드·가격 또는 할인 두 열을 복사해 붙여넣습니다. 2열은 적는 모양으로 구분해요. 숫자만 쓰면 고객 최종가(89000), %를 붙이면 할인율(15%), 앞에 -를 붙이면 할인액(-9000)이고, 할인율·할인액은 판매가 기준이에요. 상품마다 섞어 써도 돼요.
  4. 쿠폰 기간과 브랜드를 적습니다. 일반 행사는 시작·종료 날짜와 시간을 고르세요. 종료는 기본이 시작과 같은 날 23:59이고, 그 분의 끝(23:59:59)까지 적용돼요. 모바일라이브는 방송일시와 방송 시간(분)만 넣으면 쿠폰 기간이 방송 30분 전부터 방송 종료까지로 자동으로 잡혀요.
  5. 세일즈원에서 2·3번 불러오기를 누릅니다. 세일즈원 창이 상품코드 쿠폰조회에서 그 상품들을 조회하고 상품 조회/수정의 매입형태·판매가까지 받아 와서 2·3번 칸이 자동으로 채워져요. (직접 넣을 수도 있어요: 상품코드 쿠폰조회와 상품 조회/수정에서 조회한 표의 줄을 복사해 2번·3번 칸에 붙여넣기. 할인율·할인액으로만 적었다면 2번은 비워도 돼요.)
  6. 쿠폰 만들기를 누릅니다. 아래에 만들 쿠폰, 상품별 계산, 고객 최종가 미리보기가 나와요. 차단이 있으면 내용을 읽고 고친 뒤 다시 누르세요. 가격이 원하는 대로인지 꼭 한 번 보세요. 만든 쿠폰은 세일즈원 창의 에이전트에 자동으로 들어가요(④ 카드에 "보냈어요" 표시). 두 창이 안 이어져 있으면 ④ 카드의 세일즈원 입력 코드 복사 → 세일즈원 콘솔에 붙여넣기로 넣을 수 있어요.
  7. 남은 쿠폰 전부 등록을 누르면 [추가] → 칸 채우기 → 저장 → 채널(인터넷·M커머스 + VOD 매장 일괄 추가, 1번에서 VOD 전용 쿠폰을 켰으면 VOD 매장만, VOD 매장 제외를 켰으면 인터넷·M커머스만) 넣기까지 쿠폰마다 차례로 하고, 새 쿠폰코드를 기록해요. 한 장씩 하려면 쿠폰별 이 쿠폰만 등록을 누르세요. 저장만 실패했을 때는 넣은 값 아래 저장 다시 시도로 이어서 할 수 있어요.
  8. 모든 쿠폰에 쿠폰코드가 기록되면 상품-쿠폰 일괄 등록을 누릅니다. 상품 일괄등록 탭에서 양식 엑셀을 올리고 [쿠폰 상품 일괄등록]까지 눌러 줘요. 중간에 공헌이익 승인요청 창이 뜨면 요청사유 '당사직매입 상품'을 골라 [요청]까지 알아서 눌러요. 직접 올리고 싶으면 엑셀 받기로 양식 파일만 받을 수도 있어요.
  9. 승인권자에게 승인 요청을 알립니다. (승인 전에는 쿠폰이 적용되지 않아요.)
  10. 다음 작업을 시작하기 전에 쿠폰 내역 초기화를 눌러 지난 내역을 지웁니다.

주의할 점

  • 에이전트는 승인 버튼을 누르지 않아요. 등록만 해요.
  • 쿠폰이 도는 동안에는 세일즈원 화면을 클릭하거나 다른 탭으로 옮기지 마세요. 멈춰야 하면 창의 닫기를 누르세요.
  • 칸 값이 계획과 다르면 저장하지 않고 멈춰요. 이유가 창에 적혀 있으니 읽어 보고, 필요하면 직접 고쳐 저장한 뒤 직접 저장했어요 → 쿠폰코드 기록으로 코드를 넣어 주세요. 잘못 기록된 코드는 코드 고치기로 바로잡을 수 있어요.
  • 쿠폰 이름은 정해진 양식으로 자동으로 들어가요. 쿠폰설명 = 브랜드_날짜_쿠폰율/액_당사·반반, 노출쿠폰명 = 브랜드 앱할인 쿠폰율/액.
  • 고객쿠폰(등록자 신지원·이진선·나희석, 쿠폰설명에 마이샵·매장 전용·리모콘·VIP가 들어간 쿠폰)은 계산에서 빼요. 더블쿠폰은 표에 표시가 없어서 2번 칸 아래 고급 설정의 더블쿠폰 코드에 직접 적어 주세요.
  • 엔니튜드 15% 쿠폰은 당사 10% / 협력사 5% 부담으로 만들어요. 1번 칸 아래 고급 설정의 엔니튜드 체크(기본 켜짐)를 끄면 다른 위수탁 상품처럼 반반(7.5% / 7.5%)이에요.
  • 공헌이익이 마이너스가 되는 상품은 승인권자가 따로 승인해야 해요(③ 도구).
  • 기간과 고급 설정은 이 PC에 자동으로 기억돼요. 상품코드·조회 결과·매입형태·브랜드 칸은 열 때마다 비어 있고, 회색 글씨는 예시일 뿐이니 칸을 눌러 새로 넣어 주세요.
승인권자

② 쿠폰 승인 에이전트

언제 쓰나

등록자가 쿠폰을 올리고 승인 요청을 했을 때, 여러 장을 한 번에 승인하고 싶을 때.

준비물

  • 승인권자 PC, 승인권자 아이디로 로그인한 세일즈원
  • 아래 버튼으로 복사하는 승인 코드 (또는 approve-all.txt를 열어 내용 전체 복사)

순서

  1. 세일즈원 쿠폰관리 > 쿠폰등록 화면을 엽니다.
  2. 검색조건에서 결재상태 = 신규, 부담주체 = 전체로 두고 [조회]합니다. 승인하면 안 되는 쿠폰이 섞여 있으면 쿠폰코드나 등록자로 더 좁혀 주세요.
  3. F12 → Console에 승인 코드를 붙여넣고 Enter.
  4. 오른쪽 아래 🤖 쿠폰 전체 승인 창에 "쿠폰목록 총 N건을 위에서부터 차례로 모두 승인해요"가 나와요. 건수가 세일즈원 목록의 총 건수와 맞는지 확인해 주세요.
  5. N건 모두 승인 시작을 누르면 쿠폰을 하나씩 열어 [승인] → 확인창 [확인]을 알아서 누르고, 표를 아래로 내려가며 총 건수만큼 전부 승인해요. 줄마다 ⏳ 승인 중, ✅ 승인됨, ⚠️ 건너뜀이 표시되고 진행 막대가 채워져요.
  6. "끝났어요. N건 승인"이 나오면 완료예요. ⚠️ 건너뜀이 있으면 그 줄 아래 적힌 이유를 확인해 주세요.

주의할 점

  • 목록의 쿠폰은 내용을 비교하지 않고 전부 승인해요. 시작 전에 목록에 승인할 쿠폰만 남았는지 꼭 확인해 주세요.
  • 등록자 PC나 등록자 아이디로는 쓰지 마세요(등록자 ≠ 승인자).
  • 중간에 멈추려면 멈추기(지금 쿠폰까지만 하고 멈춤), 창을 없애려면 닫기. 창이 화면을 가리면 옮기기로 왼쪽으로 옮기거나 ▲접기로 접을 수 있어요.
  • 자세한 진행 기록은 창 아래 자세한 기록을 눌러 볼 수 있어요.
  • [승인]이 꺼져 있는 쿠폰(이미 승인됨, 권한 없음)은 건너뛰어요.
승인권자

③ 공헌이익 승인 에이전트

언제 쓰나

쿠폰 때문에 공헌이익이 마이너스가 된 상품의 판매 승인 요청이 여러 건 들어왔을 때.

준비물

  • 승인권자 PC, 승인권자 아이디로 로그인한 세일즈원
  • 아래 버튼으로 복사하는 승인 코드 (또는 approve-contribution.txt를 열어 내용 전체 복사)

순서

  1. 세일즈원 상품 > 승인/제한관리 > 판매 승인/제한에서 공헌이익 마이너스 승인 화면을 엽니다.
  2. [승인처리] 탭에서 결재상태 승인요청으로 [조회]합니다. 승인할 건만 보이게 좁혀 주세요.
  3. F12 → Console에 승인 코드를 붙여넣고 Enter.
  4. "목록 N건 중 패션2팀 M건은 빼고, K건을 한 건씩 차례로 승인할까요?" 창에서 건수를 확인하고 [확인].
  5. 오른쪽 아래 🤖 공헌이익 승인 창에 진행 상황이 나와요. 한 줄씩 체크 → [승인] → 확인창 [확인]을 알아서 눌러요.
  6. "끝. K건 중 K건 승인했어요. (패션2팀 M건 제외)"가 나오면 완료예요.

주의할 점

  • 패션2팀을 뺀 나머지 요청은 전부 승인해요. 조건을 비교하지 않으니 실행 전에 목록을 꼭 확인하세요.
  • 목록에서 팀 이름을 못 읽으면 패션2팀을 가려낼 수 없어서 승인하지 않고 멈춰요. 이때도 진단 내용 복사를 눌러 김지영님께 보내 주세요.
  • 승인 사유처럼 직접 입력해야 하는 칸이 있는 창이 뜨면 멈춰요. 직접 입력해 주세요.
  • 줄 체크가 확인되지 않으면 [승인]을 누르지 않고 멈춰요. 이때 창에 나오는 진단 내용 복사를 눌러 김지영님께 보내 주세요.
  • 멈추기·닫기는 ②와 같아요.

막히면

  • 붙여넣기가 안 돼요 → 콘솔에 allow pasting을 먼저 입력하고 Enter, 다시 붙여넣기.
  • 도구 창이 안 보여요 → 세일즈원 화면 오른쪽(쿠폰 에이전트는 [옮기기]를 눌렀다면 왼쪽)을 확인해 주세요. 새로고침했다면 다시 붙여넣기.
  • F12가 안 열려요 → 회사 PC 설정으로 막혀 있을 수 있어요. 김지영님께 알려 주세요.
  • "쿠폰코드를 못 찾았어요", "목록이 비어 있어요" → 결재상태 조건으로 [조회]한 뒤 다시 붙여넣기.
  • 등록 중 멈췄어요 → 창에 적힌 이유를 읽고, 세일즈원에서 해당 쿠폰이 저장됐는지 확인한 뒤 이어서 진행.
  • 그 밖의 문제는 창의 내용을 캡처해서 김지영님께 보내 주세요.
